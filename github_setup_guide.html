🔬 【超詳細解説】AIはどうやってGitHubにアップロードしているのか？

「Googleドライブ上のファイルをどうやってGitHubに送っているのか？」「なぜスマホから即座に見られるのか？」という裏側の技術と操作フローを完全解説します。

1. Googleドライブの制約と「ローカル中継」の仕組み

Googleドライブ（H:\マイドライブ）はクラウド同期を行っているため、Gitの管理ファイル（.git）を直接置くとファイルロック競合エラーが発生します。
そこでAIは、パソコン内の高速なローカルフォルダ（C:\Users\pande\prize-calendar）を専用の中継地点として用意し、そこからGitHubへ安全に送信しています。

⚠️ Googleドライブのロック問題を防ぐ工夫: H:\マイドライブ（元データ保管） ➔ C:\Users\pande\prize-calendar（Git中継地点） ➔ GitHub（クラウド） という3段構造で確実にエラーを回避しています。

2. AIが自動実行している5つのGitステップ（コマンドの全貌）

カレンダーHTMLの生成が終わると、AIのスクリプト（auto_generate_calendar.py）の末尾にある sync_and_push_to_github() 関数が自動的に起動し、以下の5段階のコマンドをミリ秒単位で連続実行しています。

1

ファイルの最新同期（Python shutilコピー）

生成された最新のカレンダーHTML（202611/calendar.html）、画像データ、トップページ（index.html）、設定ファイル（.nojekyll）を中継フォルダへ自動コピーします。

2

アップロード対象の登録（ステージング）

変更されたファイルや新しく作られた月フォルダを、Gitの送信待ちリスト（ステージ）に登録します。

# 変更があった全ファイルを送信準備リストに追加
git add .
3

履歴の確定（コミット）

「何年何月のカレンダーを更新したか」という記録（スナップショット）を作成し、変更履歴を確定します。

# 更新メッセージを添えてコミットを記録
git commit -m "Auto update calendar for 202611"
4

GitHubクラウドへ暗号化送信（プッシュ）

インターネット経由でGitHub上のリモートリポジトリ（https://github.com/jamaisvu0404/like.git）へ最新データを一括送信（push）します。

# mainブランチへデータをアップロード
git push origin main
5

GitHub Pagesによる自動ビルド＆全世界配信

データを受け取ったGitHub側のサーバーが、即座に「GitHub Pagesビルド」を自動開始。約15〜30秒で世界中のCDNサーバーに配信され、スマホから https://jamaisvu0404.github.io/like/ で閲覧できるようになります。

3. 「.nojekyll」ファイルを入れている重要な理由

GitHub Pagesは標準で「Jekyll（静的サイト生成ツール）」というシステムが動いています。このシステムは 202611 や _images のような特殊なフォルダ名を勝手に無視して除外してしまう仕様があります。
AIはリポジトリの直下に空の .nojekyll というファイルを自動配置することで、「Jekyllを無効化し、フォルダ構造やHTML・画像をそのまま100%忠実にWeb公開せよ」 とGitHubに命令しています。

🎯 まとめ: あなたが「11月も作って」とAIに言うだけで、AIが画像のダウンロードからカレンダーHTML生成、中継地点への同期、Gitコミット、GitHubへのプッシュ、GitHub PagesのWeb配信までをすべて1本のスクリプトで完全に自動処理しています！

❓ 6. トラブルシューティング ＆ よくある質問（FAQ）
Q. スマホで最新のカレンダーが表示されない A. ブラウザのキャッシュが残っている可能性があります。
スマホ画面を一番上までスクロールし、指で下に引っ張って「更新（リロード）」してください。またはブラウザの履歴・キャッシュをクリアすると即座に最新になります。
Q. メルカリ検索で違う商品が出てしまう A. AIに「〇〇のキーワードを△△に変更して」とお伝えください。
AIがキーワード変換辞書（SERIES_CLEAN_MAP など）に新しいルールを追加し、再生成してGitHubに自動プッシュします。
Q. GitHubの利用料金は本当にかからない？ A. 完全に永久無料（0円）です。
GitHub Pagesは公開リポジトリであれば完全無料で利用できます。クレジットカードの登録も一切不要です。
Q. 別のGitHubアカウントに変えたい時は？ A. AIに「GitHubのアカウントを〇〇に変更したい」とお伝えください。
AIが gh auth login を再実行して新しいアカウントに切り替えます。
