💻 2. 別のパソコン・別アカウントでの作業の流れ
1

AIにプロンプト（URL）を投げる

上記のプロンプトをAIに送信します。

2

GitHubの初回ログイン（8桁コード認証：初回1回のみ）

新しいPCで初めてGitHubへ送る時だけ、AIから「8桁のコード（例: `5F15-302C`）」が案内されます。
案内されたリンク（`https://github.com/login/device`）を開き、コードを貼って承認ボタンを1回押すだけで完了です。

3

あとは待つだけで全自動完了！

📖 4. 初心者向け用語・仕組みの解説
GitHub（ギットハブ） プログラムやHTMLファイル、画像をインターネット上に保存・バックアップしておく「安全なクラウド保管庫」です。
GitHub Pages GitHubに保存したHTMLファイルを、無料・無制限で「スマホやPCから見られるホームページ」として公開してくれる仕組みです。
index.html サイトの表紙（トップページ）です。アクセスしたときに「6月」「7月」「8月」などの月を選ぶメニューカードが表示されます。
ホーム画面に追加 スマホのブラウザで公開URLを開き「ホーム画面に追加」を押すと、アイコンができて専用アプリのようにワンタップで起動できます。
